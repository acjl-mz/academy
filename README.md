# SkillHub by ALINVEST

Plataforma moçambicana de formação prática de competências profissionais, com mentoria, avaliação por exercícios reais e certificação verificável.

## Fundação técnica
- Next.js App Router + TypeScript
- Tailwind CSS
- Supabase preparado para autenticação, base de dados e storage privado
- Arquitectura preparada para RBAC: participante, mentor, empresa e administrador
- UX responsive, mobile-first, em português pt-MZ

## Direcção visual
Referências de produto: Coursera, LinkedIn Learning e plataformas modernas de professional learning. A interface usa azul institucional profundo, azul de acção, superfícies claras, tipografia Inter + Space Grotesk, cartões discretos e hierarquia editorial forte.

## Roadmap
1. Fundação, autenticação e dashboard
2. Catálogo de skills, exercícios e submissões
3. Feedback, certificados e verificação
4. Área do mentor e área da empresa
5. Skill Labs, administração, pagamentos e gestão de conteúdo
6. Portfólio público + Skill Score
7. Publicação e domínio próprio

## Princípios de produto
- Aprendizagem orientada à prática.
- Feedback humano e accionável.
- Evidência de competência acima de consumo passivo de conteúdo.
- Certificação pública e verificável.
- Experiência simples para participantes e ferramentas robustas para mentores e empresas.
